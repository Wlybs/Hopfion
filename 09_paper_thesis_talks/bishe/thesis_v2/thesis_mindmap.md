## 四级递进子问题（论文骨架）

```
┌──────────────────────────────────────────────────┐
│  能不能造？ → 能不能活？ → 能不能动？ → 能不能用？ │
│    第3章       第4章        第5章        第6章    │
└──────────────────────────────────────────────────┘
```

### Ch3 能不能造
- 工具：四元数 + 旋转矩阵 + 环面坐标
- 产出：任意 $Q_H$、任意背景的初始态生成器
- **创新点 1**：通用工具链

### Ch4 能不能活
- 体系：阻挫交换铁磁（$J_2, J_4 < 0$，无 DMI、无 $K_{u1}$ 时）
- 三个发现：
  - 背景磁化方向 → 不影响（4 组实验）
  - 稳态尺寸 → 唯一（$R_{eq}=2.60$ nm, $r_{eq}=2.16$ nm）
  - **临界各向异性 $K_{u1,c} \in [52, 55]$ kJ/m³** ← 创新点 2

### Ch5 能不能动（最厚重）
- 极化依赖
  - vibX 有效（破对称） / vibZ 失效（保对称）
- 方向互补
  - srcX_vibX → 推 $+z$（垂直传播）
  - srcZ_vibX → 推 $-z$（沿传播）
- 频率响应
  - srcZ 多峰，1100 GHz 最强、100 GHz **唯一反向**
- 幅度响应
  - $B_0 \geq 0.5$ T 有效，$\leq 0.1$ T 死区
- **创新点 3**：单源频率切换 → 双向控制
  - 100 GHz 推到 +18.6 nm → 切 1100 GHz 急速回退到 +4.0 nm

### Ch6 能不能用
- 微磁学 ↔ 神经元 映射表
  - 频率死区 ≙ 输入滤波 / 激活阈值
  - 正交位移 ≙ 兴奋 / 抑制突触
  - 先积累后释放 ≙ LIF 膜电位
  - 幅度→速度 ≙ 突触权重
- 概念器件：微波天线 → 磁轨道 → TMR 读取
