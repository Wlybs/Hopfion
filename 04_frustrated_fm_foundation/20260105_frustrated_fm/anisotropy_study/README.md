# Anisotropy Study — Frustrated FM Hopfion

**研究问题**：单轴各向异性 Ku 如何影响 Hopfion 的尺寸与稳定性？临界值 Ku_c 在哪里？

**体系参数**（两个子实验共用）：
- 100³ 网格，0.5nm/格，PBC(1,1,1)，EnableDemag=false
- Ms=1.5×10⁵ A/m，Aex=5×10⁻¹² J/m，J2=−0.164J1，J4=−0.082J1
- anisU = (0,0,1)，alpha=0.2

## 实验设计说明

两个实验使用了**不同的初始态**，这是有意设计：

| | 实验1 (`size_vs_ku`) | 实验2 (`ku_critical_sweep`) |
|---|---|---|
| 初始态 | `hopfion_Qh1_FM_SMALL.ovf`（R≈3.1nm） | `hopfion_z_R8_r4.ovf`（R=8nm） |
| 用途 | 验证从小尺寸能否收敛到同一吸引子 | 主体实验：平衡尺寸曲线 + Ku_c 临界值 |
| 科学意义 | 证明吸引子唯一（与初始态无关） | 给 Hopfion 最大生存优势，测真实临界点 |

**为何 Ku_c 测量必须用大初始态**：在 Ku 接近 Ku_c 时，小初始态可能在弛豫前就湮灭，导致测出的 Ku_c 偏低。大初始态保证测到的是系统真正的亚稳态边界。

**交叉验证**：两组实验在重叠 Ku 点收敛到一致平衡尺寸（见综合结论），证明吸引子唯一，结果可靠。

## 实验1：吸引子唯一性验证 (`size_vs_ku/`)

**初始态**：`hopfion_Qh1_FM_SMALL.ovf`（R≈3.1nm）｜**运行时长**：3ns｜**Ku 范围**：0 ~ 12k J/m³

| Ku (J/m³) | R @ 3ns (nm) | r @ 3ns (nm) | 状态 |
|---|---|---|---|
| 0 | 2.60 | 2.16 | 存活 |
| 2,500 | 2.35 | 1.95 | 存活 |
| 5,000 | 2.29 | 1.81 | 存活 |
| 7,500 | 2.17 | 1.74 | 存活 |
| 10,000 | 2.17 | 1.64 | 存活 |
| 12,000 | 2.00 | 1.64 | 存活 |

**结论**：小初始态在所有 Ku 点均收敛至与实验2一致的平衡尺寸，验证吸引子唯一性。

**结果图**：`results/summary_Rr_vs_Ku1.png`，`results/R_r_vs_time.png`

## 实验2：主体实验 (`ku_critical_sweep/`)

本目录合并了粗扫（0~50k，8点含新增 Ku=40k）和细化扫描（52~58k，5点含 2026-03-25 新增 56k/57k），以大初始态覆盖完整 Ku 范围。

**初始态**：`hopfion_z_R8_r4.ovf`（R=8nm，r=4nm）｜**运行时长**：1ns/点

### 完整扫描结果（Ku=0 ~ 58k，共 12 点）

| Ku (J/m³) | R @ 1ns (nm) | r @ 1ns (nm) | 状态 |
|---|---|---|---|
| 0 | 2.63 | 2.22 | 存活 |
| 5,000 | 2.35 | 1.85 | 存活 |
| 10,000 | 2.17 | 1.64 | 存活 |
| 20,000 | 1.82 | 1.54 | 存活 |
| 30,000 | 1.82 | 1.38 | 存活 |
| 40,000 | 1.69 | 1.30 | 存活 |
| 50,000 | 1.56 | 1.24 | 存活 |
| 52,000 | 1.46 | 1.27 | 存活 |
| **55,000** | — | — | **消解** |
| **56,000** | — | — | **消解**（2026-03-25 新增） |
| **57,000** | — | — | **消解**（2026-03-25 新增） |
| 58,000 | — | — | 消解 |

**结论**：**Ku_c ∈ (52k, 55k) J/m³**，精度 3k J/m³。55k/56k/57k/58k 全部消解，确认 Ku_c 上界为 55k。

**结果图**：`results/summary_Rr_vs_Ku1.png`，`results/R_r_vs_time.png`，`results/survival_table.txt`

## 综合结论

```
稳定区间：Ku = 0 ~ 52k J/m³
临界值：  Ku_c ∈ (52k, 55k) J/m³
消解区间：Ku > 55k J/m³
```

## 下游使用

**Ku=10k 被选为自旋波驱动实验的标准参数**，理由：
1. 距 Ku_c (52~55k) 充分远，安全裕量 >5倍
2. Hopfion 尺寸适中（R=2.17nm），便于追踪
3. 自发漂移极小（见 `centered_stability_test/`）
