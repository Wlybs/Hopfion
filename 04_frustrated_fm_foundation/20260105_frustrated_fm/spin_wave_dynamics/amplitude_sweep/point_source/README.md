# 点源驱动 Hopfion：球面波激发与响应研究

**bd issue**: Hopfion-rt4.3
**状态**: 待验证（物理猜想阶段）
**创建日期**: 2026-03-31

---

## 研究动机

前期实验（`direction_coupling/`）使用薄板源（0.5 nm 厚度覆盖整个截面），产生的是**平面自旋波**。平面波波前平坦，Hopfion各部分感受到相同相位的扰动，耦合具有平移对称性。

本研究改用**单格点源**（`DefRegionCell`），产生球面波，预期与平面源在物理机制上有本质区别。

---

## 物理猜想（待实验验证）

### 猜想 1：波前几何导致不对称耦合

| 维度 | 薄膜源（平面波） | 点源（球面波） |
|------|----------------|--------------|
| 波前形状 | 平坦，单一 k 方向 | 球形发散，各向同性 k 谱 |
| Hopfion 受力对称性 | 单侧均匀推动 | 梯度驱动，两侧相位差随距离变化 |
| 振幅衰减 | 不衰减（平面波） | ~1/r 衰减，耦合强度随距离敏感 |

**预测**：点源产生的磁子流在 Hopfion 近端与远端幅度不同，可能产生类似辐射压力的梯度力，驱动 Hopfion 向远离点源方向移动。

### 猜想 2：全谱 k 激发提升共振耦合效率

平面源主要激发垂直于源面的单一 k 分量；点源的 Fourier 变换为平坦谱，**同时激发所有 k 分量**。

**预测**：点源对 Hopfion 固有频率（约 440 GHz 共振模式）的能量注入效率可能更高，即便在相同激励幅度下，Hopfion 的位移响应也更强。

### 猜想 3：漂移方向偏离 z 轴

在平面源实验中，观测到的漂移主要沿 z 轴（极化方向驱动）。点源位于特定位置时，球面波对 Hopfion 的驱动力方向由**源到 Hopfion 的连线**决定。

**预测**：
- 若点源在 Hopfion 侧面（如 x 或 y 方向），漂移方向可能出现**非 z 轴分量**，甚至产生螺旋轨道运动
- Hall 角（横向漂移 / 纵向位移）与平面源结果不同

### 猜想 4：近场 vs 远场效应

平面波不存在近场/远场之分；点源在近场（距离 < 波长）激发倏逝场，行为与远场（传播波）不同。

**预测**：将点源放置在 Hopfion 核心附近（~2 nm）与远处（~20 nm）时，Hopfion 响应会有显著差异，可用于验证是否存在非辐射耦合机制。

## 实验设计

### 对照变量

1. **点源位置**：Hopfion 侧面（x/y/z 方向）× 不同距离（5/10/20 nm）
2. **极化方向**：B_ext 沿 X / Z（对应平面源实验已有结果）
3. **频率**：440 GHz（已知共振频率）
4. **幅度**：与平面源保持一致，便于直接对比

### 基准对照

以 `direction_coupling/sw_srcX_vibX.mx3` 作为基准（相同频率、相同极化、相同幅度），
对比点源在 x=-10 nm 处与平面源的 Hopfion 位移、漂移方向、核心细胞数变化。
