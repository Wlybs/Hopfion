# Scientific source registry

This file is an index anchor, not a substitute for the cited sources. Exact source
locators for external figures are recorded in `FIGURE_MANIFEST.csv`. Thesis chapter
IDs refer to the matching versioned chapter sources in the original project. Items
marked unverified remain unverified; this delivery does not invent missing papers,
metadata, simulations, or results.

The current project-status source is `00_project_index/HOPFION_PROJECT_STATUS.md`.

`plot_data.py` is a reference-only provenance producer: it reads excluded source
fields solely to emit bounded CSV plotting data and is not a simulation run entry.

Previously unresolved full-field consumers are retained as reference-only source
code in this handoff unless independently registered as an active portable run;
reference-only is a delivery classification and makes no simulation-validity claim.
